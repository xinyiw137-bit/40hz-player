# 40Hz 伽马波音乐播放器

一个给阿尔茨海默症患者使用的音乐工具：让音乐**音量以每秒 40 次（40Hz）的节奏轻轻起伏**，
通过听觉产生 40Hz 伽马波夹带（gamma entrainment），用于辅助放松和认知刺激。

> ⚠️ **重要声明**：本工具基于仍在研究中的方法（MIT 蔡立慧实验室的 GENUS——Gamma
> ENtrainment Using Sensory stimuli）。动物实验显示 40Hz 感觉刺激能减少淀粉样蛋白沉积、
> 改善认知，人类临床试验也在进行中，但**它仍是实验性方法，不是医疗器械，不能替代医生的
> 诊断与治疗**。使用前请咨询医生，音量保持舒适、不要过大。

---

## 两种使用方式

### 方式一：网页播放器（推荐，实时可调）

1. 双击打开 `40hz_player.html`（用 Chrome / Edge 浏览器）。
2. 点「选择音乐文件」，选一首 MP3 / WAV。
3. 点「▶ 播放」，即可听到音乐音量以 40Hz 有节奏地起伏。
4. 用滑杆实时调节 **调制频率**（默认 40Hz）、**调制强度**（起伏幅度，建议先 30–50%）、音量。

- 无需安装任何软件，所有处理都在本机浏览器内完成，**音乐不会上传到网络**。
- 适合护工/家属现场操作，实时给老人听。

### 方式二：离线转换（把音乐预先变成 40Hz 版本）

把音乐转成 40Hz 版本后，可以拷进老人的 MP3 / 收音机 / 手机，随时播放，无需电脑。

```bash
pip install numpy soundfile          # 首次需安装
python convert_40hz.py 原曲.wav 40Hz版.wav                # 默认 40Hz / 50%
python convert_40hz.py 原曲.flac 40Hz版.wav --depth 0.3   # 更轻柔
```

- MP3 请先转成 WAV（或用网页版，浏览器能直接播 MP3）。

## 原理说明

**"旋律的赫兹调到 40Hz" 是一个常见误解**：40Hz 是一个很低的单一低音（约 E1，低于正常音乐
音域），把整首歌压到 40Hz 会变成听不清的嗡嗡声。

科学上有依据的做法是 **40Hz 振幅调制**：

```
输出(t) = 音乐(t) × (1 + 强度 × sin(2π × 40 × t))
```

也就是音乐正常播放，但**音量按 40Hz 起伏**（每秒 40 次的"颤音/拍频"）。这种有节奏的
听觉刺激能在脑内诱发 40Hz 伽马振荡——这正是 GENUS 研究的核心思路。

## 参数建议

| 参数 | 默认 | 说明 |
|------|------|------|
| 调制频率 | 40 Hz | 研究验证的伽马频段，建议保持 40 |
| 调制强度 | 50% | 刚开始建议 30–50%，适应后再加大 |
| 音量 | 60% | 以老人感觉舒适为准，切勿过大 |
| 循环播放 | 开 | 适合连续 40Hz 刺激 |

## 建议使用时长

每次 20–40 分钟为宜，每天 1–2 次，循序渐进。如老人感到烦躁或不适，立即停止并降低强度。
